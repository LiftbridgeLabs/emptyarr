Timestamp Repair
Configure local Plex databases or pair one repair-only worker. Empty Trash remains controlled by this main Emptyarr instance.
Docker mounts cannot be created from inside Emptyarr. Add each Plex database directory read-only and only the narrow symlink prefixes you approve read/write, then use Discover databases below.
How do I find the Plex database directory on Unraid?
Open the Plex container’s edit screen and note its host appdata path. Inside that appdata directory, the required folder ends with Library/Application Support/Plex Media Server/Plug-in Support/Databases. Map that exact directory read-only to a distinct path such as /plex-db/streamstead. The Discover button finds the database file after the container is recreated.

Login Credentials

API Token
Use this token to authenticate API calls from scripts or automations without a browser session. Add it as an HTTP header: X-API-Token: <token> Typical uses include Home Assistant buttons, scheduled scripts, uptime checks, external dashboards, and safely triggering a run or reading status/history/logs without storing the UI password. Rotate or revoke it independently if an automation is retired.
